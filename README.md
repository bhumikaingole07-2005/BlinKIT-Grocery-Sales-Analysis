# 🛒 BlinkIT Grocery Sales Analysis

## 📌 Project Overview

This project presents an interactive Excel Dashboard created using BlinkIT Grocery Sales data. The dashboard helps analyze sales performance, customer behavior, product categories, and business KPIs.

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

## 📊 Dashboard Features

- Total Sales
- Total Orders
- Average Sales
- Category-wise Sales
- Outlet Analysis
- Interactive Filters
